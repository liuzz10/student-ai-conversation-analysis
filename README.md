# Student–AI Conversation Analysis

A reusable prompt for helping educators notice evidence of student thinking in AI-supported project conversations and prepare for more focused check-ins.

## What the prompt does

It helps a teacher:

- Summarize a student–AI project conversation.
- Look for evidence across seven learning dimensions, using descriptions and examples as reference points.
- Distinguish student contributions from AI suggestions.
- Quote the conversation and flag what cannot be determined.
- Prepare three open-ended teacher questions and one possible next step for the current project milestone.

The prompt does not grade students, assign mastery scores, or treat a single conversation as a complete picture of learning.

## How to use it

1. Open [prompt.md](./prompt.md) and copy the prompt.
2. Add the project context and current milestone, if known.
3. Paste a de-identified student–AI conversation into the indicated section.
4. Review the analysis as a starting point for teacher judgment and conversation.

Before using a transcript, remove names and other identifying or sensitive information. Use only conversations you are authorized to process, and follow your school or organization’s policies for student data and AI tools.

## Learning dimensions

1. Agency & Ownership
2. Problem Decomposition & Incremental Development
3. Monitoring & Adaptation
4. Decision-Making & Trade-offs
5. Evidence-Based Reasoning
6. Understanding & Knowledge Integration
7. Communication Efficiency & Precision

Descriptions and illustrative examples for each dimension are included in the prompt.
